# Student Grade Tracker

## Project Overview

Student Grade Tracker is a Java console application developed as part of the CodeAlpha Java Internship.

The application allows users to enter student details and grades and generates a summary report.

## Features

- Add student details
- Store student records using ArrayList
- Display student information
- Calculate average grade
- Find highest grade
- Find lowest grade
- Determine pass/fail status
- Count passed and failed students
- Validate grades between 0 and 100
- Generate a summary report

## Technologies Used

- Java
- ArrayList
- Object-Oriented Programming
- Scanner
- VS Code
