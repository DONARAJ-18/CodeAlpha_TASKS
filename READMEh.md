# 🏨 Hotel Reservation System

A console-based Java application for searching, booking, managing, and cancelling hotel room reservations.

## 📌 Project Overview

The Hotel Reservation System allows users to search available rooms based on room categories, make reservations, cancel bookings, simulate payments, and view booking details.

The project is developed using Java and demonstrates Object-Oriented Programming (OOP) concepts along with File I/O for storing room availability and reservation data.

## ✨ Features

* 🔍 Search available hotel rooms
* 🛏️ Different room categories:

  * Standard
  * Deluxe
  * Suite
* 📅 Book a hotel room
* ❌ Cancel a reservation
* 💳 Simulate payment processing
* 📋 View booking details
* 🏨 Manage room availability
* 💾 Store room and reservation data using File I/O
* 🖥️ Console-based interface

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* File I/O
* VS Code

## 🧩 OOP Concepts Used

* Classes and Objects
* Encapsulation
* Constructors
* Methods
* ArrayList

## 💾 File Storage

The system uses text files to store data:

* `rooms.txt` – stores room details and availability
* `reservations.txt` – stores reservation details

